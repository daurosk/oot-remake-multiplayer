# gohma-door (#150, #178): Gohma made by the game's own trigger. A warp straight into the boss
# room skips EntryBossRoom (Logic/Enemy_DungeonBoss_Gohma_Prefab), so the gohma scenario never
# had a boss. Here both load at the Deku Tree entrance and are put in the corridor before the
# boss door (floor about y 47.5 at x -12..-4, z 62..71; the door InsideTheDekuTree SwitchShutter
# at -1.0 52.4 67.5, Gohma placed at 18.5 60.0 67.8), then walk in through the door.
# The kit saves have the Deku Tree beaten; both games clear the boss flags with setflag after
# the load (below; Gohma_DefeatBoss alone was not enough, issue 178). Pass also needs "setflag ... set".
# A (P1) goes in first and then stands at the room's edge, never hitting; B (P2) comes in 10 s
# later, stays near Gohma and shoots the slingshot at it three times.
# Expect: "+ Enemy_DungeonBoss_Gohma" in both logs (the boss exists at all); boss lines "intro
# started"/"intro ended" in both; the owner moves to P2 (server "boss_to_near" or a "share owner
# ... is player 2" line for Enemy_DungeonBoss_Gohma) once B is near and A far; B's seed:
# "stunned here ..." and "share damage 0", or a DAMAGE hand-over; eggs/larvae: "share hatched".
#! noload
#! start coop: test warp done
#! switches LICHII_COOP_DEBUG_BOSS=1,LICHII_COOP_DEBUG_OBJECTS=1,LICHII_COOP_CHEATS=1
#! timeout 480
mark start
warp InsideTheDekuTree Entrance
wait 1200               # the title screen
mark title
press A
wait 180
press A
wait 180
press A
wait 300
press A                 # loads the save, then the warp
wait 2400
mark a-in
# The kit saves have the Deku Tree beaten (issue 178, gohma-door-b): Gohma_DefeatBoss and
# Dm_Deku_BossOut were cleared, but the trap event, the intro and the room's battle state were
# still marked as played, so the boss room's one-shot trigger (Area_6c3c -> EventRequestActor
# InsideTheDekuTree_BossArea_ShutIn -> EntryBossRoom) never fired. Clear them in this game only
# (none is shared) while still in the entrance room, before the boss room loads.
setflag HavePlayedEvent.InsideTheDekuTree_BossArea_ShutIn 0
setflag HavePlayedEvent.Dm_Deku_BossIn 0
setflag HavePlayedEvent.Dm_Deku_BossOut 0
setflag HavePlayedEvent.InsideTheDekuTree_BossArea_Warp 0
setflag InsideTheDekuTree_BossArea_ShutIn 0
setflag InsideTheDekuTree_BossArea_ChangeENVForBoss 0
setflag Gohma_IsLightingForBattle 0
setflag Gohma_DefeatBoss 0
wait 120
place -12.0 48.5 66.5   # the corridor, 11 m before the door
wait 240
mark placed
goto -4.0 67.5 1.0 600
goto 6.0 67.6 1.5 600   # through the door: the game's own boss trigger
mark door
wait 1800               # the intro
mark intro
goto 7.5 95 1.5 900     # the edge, about 28 m from the room's centre and from Gohma
mark a-at-edge
wait 1800
mark handover
wait 3600
mark stun
wait 2400
mark end
