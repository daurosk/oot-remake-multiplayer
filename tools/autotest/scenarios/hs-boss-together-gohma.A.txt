# hs-boss-together-gohma (Hookshot/Longshot; tracker row 130, GitHub #173): A and B walk in through Gohma's door
# at the same moment (the same script, side by side). Player report on 0.11.3: "a softlock with Gohma when we tried
# entering her chamber at the same time ... He was able to beat her and I wasn't."
# SAVE: as hs-boss-fix-gohma (a pre-Gohma save in both lanes' baselines; the setflags clear the boss flags again).
# Run: tools\autotest\run.ps1 -Runtime hookshot -Scenario hs-boss-together-gohma [-Lane 1]
# PASS (proof lines and shots):
#  1. Both: the intro starts in both games within ~1 s ("Dm_Deku_BossIn: our game started it" in one or both;
#     the higher number then "started it too: theirs leads (lower number)" or "ours started with player N's").
#  2. CONTROL: both "test goto ... reached" after a-after-intro / b-after-intro; shots a-moved / b-moved show each
#     Link at its goto target, free (a Link held in the intro = the softlock, FAIL).
#  3. Gohma leaves her pre-battle phase in both games ("ready to own the boss" in both, no copy at the intro spot:
#     no BossAppear asked twice in one game, the 10 s bosses line's brain changes > 0 in the owner).
#  4. ONE DEATH: after the owner's kill (both scripts send kill; the copy's is held at 1) she dies in both games,
#     the death cutscene in both (shots a-k2 / b-k2).
# The job also greps 'coop: boss', 'now ours', 'unready', 'handover' to name where a FAIL comes from.
#! noload
#! start coop: test warp done

mark a-in
wait 600
mark a-intro

wait 900

mark a-moved
wait 1200
mark a-watch

hold ZL+ZR 60
hold ZL 30
mark a-seed
wait 120
hold ZL+LSTICK_UP 90    # locked on: walk up to the eye
hold ZL+Y 8
wait 12
hold ZL+Y 8

wait 900
