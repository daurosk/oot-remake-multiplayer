# hs-dodongo-native (Hookshot, branch native-boss-dodongo): King Dodongo with native boss sync
# (docs/dungeons-boss.md, "Native boss sync"): A owns him, B's copy takes A's brain and action verbs
# through the game's own functions; his babies and fire are made only by A's game.
# NEEDS a hookshot.exe whose hook table has rows 4 and 5 (hookshot/src/hos_coop_bosses.h); without them
# the log says "native sync off ... not wrapped" and the run is INCONCLUSIVE.
# Route: both warp into the boss rush's Dodongo room (DodongoStage: it places its own King Dodongo, as
# gohma-sync's GohmaStage; no kit save is from before him). A throws a bomb into his mouth when he
# inhales, three times; B throws its own bombs a little later. Fallback with a real save: Alex's own
# save before King Dodongo as an ALEX TEST (the boss room of DodongoCavern).
# PASS (proof lines):
#  1. Both: "coop: bosses: native sync on (brain verbs wrapped, action verbs wrapped)".
#  2. A: "coop: bosses: Enemy_DungeonBoss_Dodongo: native boss sync on (BSA 0x..., ours)"; B the same with "a copy".
#  3. B: "Enemy_DungeonBoss_Dodongo: the owner's verbs came (brain N): the copy's own brain is skipped from now".
#  4. Every 10 s: A "ours sent N brain + N action verbs" growing; B "N own skipped, N brain + N action verbs put in"
#     growing, and "N own minions not made" once he calls his babies.
#  5. Babies: A "share" a made Enemy_DungeonBoss_Dodongo_SpawnBabyDodongo (OBJECT_SPAWN); B makes it as a copy;
#     never two babies at one spot on B's screen (screenshots b-babies).
#  6. Fire: one fire stream on both screens (DungeonBossDodongo_Bullet_*: "not made: a copy enemy's own shot" in B).
#  7. Screenshots a-bomb1..3 / b-bomb1..2: the same action on both (walking, inhaling, rolling, stunned).
#  8. A bomb swallowed on either screen stuns him on both; B's sword on the stunned head -> "share damage" in B
#     and A's life for him falls. One death and one outro (Dm_DodongoCave_BossOut) for both.
