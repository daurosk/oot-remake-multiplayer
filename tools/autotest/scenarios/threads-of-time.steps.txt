# threads-of-time (issue 193): the Threads of Time tab opens for a player who never saw the owl,
# and its quest steps are the same in both games. Run:
#   tools\autotest\run.ps1 -Scenario threads-of-time
# Needs a build with setenum (coop_testinput) and the quests store (coop_quests.cpp).
# 1. A shuts the tab (UI_IsFinishChallengeMenuOpenEvent 0, a shared story flag): B's goes to 0.
#    Both put SubEvent_GetScarecrow (0x9472302b) at NotReady: a lowered max-rule value stays in
#    that game, so each sets its own. B opens the pause menu and steps through the tabs (shots).
# 2. A opens the tab (flag 1, as the owl's event does) and moves the scarecrow quest to IntoTheFuture.
#    B's flag goes to 1 and its quest to IntoTheFuture. B opens the pause menu again: the tab opens.
#    Look at B's shots: tab masked in tot-b-locked-*, open in tot-b-open-*. Say whether it opened
#    at once (no scene change between).
# 3. B moves the quest to Complete: A's game takes it. A opens the tab (shots).
#    The kit saves are at PlayScarecrowSong and the host keeps the group's highest step, so the
#    raised steps must be above it (IntoTheFuture, Complete). If a kit save gets autosaved at
#    Complete, quest-to-a cannot pass again: reload a save from before (bigrun2 had the old steps).
