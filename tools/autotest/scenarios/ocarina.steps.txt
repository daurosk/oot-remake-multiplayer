# ocarina (issue 86), checked by itself: A takes out the Ocarina and plays notes (ocarina.A.txt);
# B watches. Playing freely is not a cutscene: no hide in A, no hold in B while it plays.
# Run: tools\autotest\run.ps1 -Scenario ocarina
# Shots at "playing*": B's window shows A's puppet with the Ocarina; A's window still shows B.
# ocarina-played-B 0 = no quick-select try reached the Ocarina: INCONCLUSIVE (see ocarina.A.txt).
# no-hide-A counts only between A's "coop: test mark start" and "mark end" lines (not the load);
# no-hold-B only after B's first "plays 'Ocarina" line. A FAIL line's time should still be read
# against the playing* marks in steps.txt.
#! switches LICHII_COOP_PUPPET=1,LICHII_COOP_CHEATS=1,LICHII_COOP_DEBUG_ANIM=1,LICHII_COOP_OBJECTS=1,LICHII_COOP_DEBUG_OBJECTS=1
start A B
load A B
expect both-in A=1 B=1
play A ocarina.A.txt
lines ocarina-played-B B min=1 (?<!fairy )coop: puppet: P\d+ plays 'Ocarina
lines no-hold-B B max=0 (?<!fairy )coop: puppet: P\d+ show -> hold \(their cutscene\)(?<=plays 'Ocarina[\s\S]*)
lines no-hide-A A max=0 (?<!fairy )coop: puppet: P\d+ show -> hide \(our cutscene\)(?<=coop: test mark start [\s\S]*)(?=[\s\S]*coop: test mark end )
expect after A=1 B=1
