# save-refresh (player report 124): a guest joins on the title; once the host's save is written into its co-op folder
# and the game is switched to it, the title has the game re-read its save list (CoopSave RemountLocked -> coop_title
# RefreshSaveList) and arranges the open title for it (ArrangeTitle), so Continue shows without a restart.
# Two preps, same steps (the offline job row-124-continue-run does both, and puts the saves back):
#   first boot: game B's autotest-save without its slot_NN folders (a guest with no save: New Game, Options before);
#   own save:   game B's autotest-save as it is (Continue before and after).
# PASS: the lines below AND the shots: b-title-after (Continue first on B's title), b-load-list (the load list with the
# host's slot), b-in-game (B plays that slot).
#! switches B:LICHII_COOP_HOST_SAVE=1,B:LICHII_COOP_TEST_OWN_SAVE=0
#! timeout 480
start A B
sleep 10
shot b-title-before
load A
sleep 20
shot a-loaded
sleep 60
shot b-title-after
lines b-switched B min=1 coop: save: now playing from the co-op save folder
lines b-list-asked B min=1 coop: title: save list: reset \(state 0\), read started
lines b-list-read B min=1 coop: title: save list: read again by the game: a save yes
lines b-arranged B min=1 coop: title: save list: the open title's buttons arranged as its OpenTitle does for this list: Continue, New Game, Options
lines b-not-kept B max=0 coop: title: save list: the open title keeps its buttons
play B save-refresh.press.txt
shot b-load-list
play B save-refresh.back.txt
shot b-title-back
load B
sleep 20
shot b-in-game
lines b-no-crash B max=0 unhandled exception|fault at|coop: null read
