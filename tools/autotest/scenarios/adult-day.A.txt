# adult-day: as adult.A.txt, but in Kakariko by day (KakarikoVillage_Adult, Kakariko_WellSide) so the adult puppet can be seen (#111); B is adult in the same scene (a child B in KakarikoVillage_Child keeps the puppet idle: other scene).
# Run with -NoLoad: the warp is asked before the save is loaded, because the game takes it
# only during an event (the one after a save loads), and this file loads the save itself.
#! noload
#! start coop: test warp done
mark start
warp KakarikoVillage_Adult Kakariko_WellSide
wait 1200               # the title screen
mark title
press A
wait 180
press A
wait 180
press A
wait 300
press A                 # loads the save, then the warp
wait 2400                # the save loads, then the warp lands (about 30 s)
mark after
wait 600                # B lands too and backs off
mark start-walk
stick 0 0.4 90          # walk forward slowly
mark walk
stick 0 0.4 40
mark walk2
hold LSTICK_UP+B 30     # run (B held)
mark run
stick 0 -1 30           # turn and come back
mark back
wait 40
press Y 8               # sword swing
wait 6
mark attack
wait 10
mark attack2
wait 60
mark end
