# hs-pause-tab (Hookshot only; issue 264, PR #281 + pause-tab-finish): the game's own pause menu's fifth tab,
# Multiplayer, and its page, in both games. Needs the game built with patch 0030 (#281's) and the puppet pack made
# with --pause-tab (the kits pass it; the pack log says "pause menu: the Multiplayer tab and page").
# Pass, by the shots of BOTH games (screenshot proof; the lines below only say what the module did):
#   system         the System page, five tabs in the strip: Collection, Equipment, Items, System, Multiplayer (dim)
#   page           the Multiplayer page over System: five rows in the System page's own buttons ("In a session",
#                  "Session details", "Players: 2", "Let in: the host does" or "Resync from host", "Leave: restart the game" in a launcher session or
#                  "Leave" in one started from the menu), the fifth tab lit, System's not; no controller picture
#   page-down      the game's cursor frame one row lower, on our rows
#   system-back    System's page and its tab lit again, its own buttons
#   closed / walking   the menu closed, the game plays (Link walks in A's)
# The views (b4093233), cursor moved to the top first (DUP x5):
#   a-session      A (host): "Hosting: 2 players", "Copy room: ..." or "Copy invite code", "Copy same-network line",
#                  "Copy VPN line", "Back"; a-session-back: the five rows again (B in a view does not close the menu)
#   a-players      "<A> (you)", "<B>", " ", " ", "Back"
#   a-player       B's view: "Teleport to <B>", "Mute their voice (you)", "Mute their chat (you)", "Host controls", "Back"
#   a-host-controls (not marked by A: it is the launcher session's guest; the hosting game's script marks it)  "Mute voice for everyone", "Mute chat for everyone", "Kick <B>", "Ban for this session", "Back"
#   a-player-back / a-players-back (A: two B presses; a third would close the strip)   B goes one level up: B's view, the Players view, the five rows
#   b-session      B (guest): "Joined <A>", "With 2 players", (co-op's hint or " "), "Resync from host" or " ", "Back"
#   b-letin-row    the cursor on Let in: "Resync from host" or "Let in: the host does" (not pressed)
#   b-players      "<A> (host)", "<B> (you)", " ", " ", "Back"; b-player: A's view (Teleport, two mutes, no Host
#                  controls); b-main-back: the five rows
# A only, Leave in a launcher session (both games here start from the launcher, so co-op cannot be left from the menu):
#   leave-row      POSITIVE CHECK beside no-stop-A: the cursor on the fifth row, which reads "Leave: restart the game"
#   leave-confirm  after one A: the same five in-session rows (at most the game's own hint), co-op still on
#   leave-after    after the second A: STILL the five in-session rows ("In a session" ...), no idle page ("Host a game")
#   leave-system   System back, the game's own tabs work as ever
#   walking        the menu closed, Link walks
# The co-op idle path (Leave twice -> "Host a game", "Join a game", ...) needs a session started from the menu: not here.
#! switches LICHII_COOP_PUPPET=1
#! timeout 420
start A B
load A B
sleep 10
play A hs-pause-tab.A.txt B hs-pause-tab.B.txt
lines page-shown-A A min=2 coop: pause tab: our page shown \(R on System\)
lines page-shown-B B min=1 coop: pause tab: our page shown \(R on System\)
lines system-back-A A min=2 coop: pause tab: System back
lines system-back-B B min=1 coop: pause tab: System back
lines texts-A A min=5 coop: pause tab: live text: Coop_Live_0[0-4] at
lines texts-B B min=5 coop: pause tab: live text: Coop_Live_0[0-4] at
lines tab-word-A A min=1 coop: pause tab: the fifth tab filled \(its word set
lines tab-word-B B min=1 coop: pause tab: the fifth tab filled \(its word set
# proof-0116: A is the guest of a launcher session: Leave reads 'Leave: restart the game' and does not stop co-op (ae3dfe05),
# so the idle half needs a session started from the menu; not checked here.
lines no-stop-A A max=0 coop: pause tab: the second A: co-op stops
lines no-bad-panes A max=0 not both parts: the Multiplayer page stays off
shot end
